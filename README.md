# EXECUTION — Do or Die

Native SwiftUI iOS application for shortening the time between thought and execution.

## Run
Install Xcode and XcodeGen (`brew install xcodegen`). In the repository root run `xcodegen generate`, then open `Execution.xcodeproj`, select your signing team, and run on an iPhone or simulator. Minimum iOS 18. No backend or external dependencies are required for the initial build.

## Scope
The initial build is local-first: commitments, priorities, deadlines, live in-app countdowns, completion history, and opt-in deadline reminders. Native widgets, ActivityKit/Dynamic Island, StandBy, Siri/App Intents, and accountability partner invitations are follow-up milestones, not yet implemented. Notification delivery is subject to system permission and settings.

## Product principle
Designed for winning. Shorten the time between thought and execution. Track progress without shaming users; missed commitments remain actionable.
